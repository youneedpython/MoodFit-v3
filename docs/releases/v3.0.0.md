# MoodFit v3.0.0

**신체 리듬과 날씨로 오늘의 컨디션을 읽고, 어울리는 음식과 음악을 추천하는 웰니스 웹 서비스**의 첫 정식 Release입니다.

계획한 Task 17개(Core MVP 12개 + Post-MVP 보완 5개)를 모두 마친 상태이며,
AI Coding Agent와 Harness(명세 → 계획 → 승인 → Task → 구현 → 검증 → 기록) 방식으로 개발했습니다.

![MoodFit Dashboard](https://raw.githubusercontent.com/youneedpython/MoodFit-v3/v3.0.0/docs/images/readme/dashboard.png)

## 주요 기능

- **Daily Check-in**: 심박수, 호흡수, 수면 점수, 스트레스, 에너지, 기온, 날씨를 입력하면 바로 분석 결과를 보여 줍니다.
- **Dashboard**: 최신 Mood와 Wellness Score, 상태 요약, 5가지 Body Metric, 추천 음식 2개 / 음악 2개를 한 화면에 보여 줍니다.
- **History / Trend**: 최근 7일 Wellness Score 그래프와 기록별 지표, 날씨, 추천 이력을 보여 줍니다.
- **반응형 화면**: 390px 모바일부터 데스크톱까지 같은 기능을 제공합니다.

분석은 외부 AI / API 없이 정해진 Rule(DEC-014)로 계산하며, 같은 입력에는 항상 같은 결과를 반환합니다.
분석 기준은 교육용 Product Heuristic이며 의학적 진단 목적이 아닙니다.

## 품질 검증

- Frontend Test 81건 (화면, 입력 검증, API Client, Timezone 고정 날짜 표시, API 명세 동기화)
- Backend Test 68건 (API Validation, Wellness Rule 경계값, Repository, API 계약, 실제 MySQL 연동)
- DB 연동 테스트: Testcontainers `mysql:8.0.46`으로 Flyway Schema / 저장 / 조회 검증
- API 계약 테스트: Backend 응답, Frontend Type, API 명세 예시가 `contracts/`와 같은지 검증
- Local Verification(`scripts/verify.ps1`, `scripts/verify.sh`)과 GitHub Actions CI가 같은 순서로 실행
- CI 결과를 GitHub Actions Step Summary로 자동 기록, Task 완료 시 GitHub Milestone 자동 Close
