## 달라진 점

### 1. 오늘 기록 여부에 따라 달라지는 Dashboard

이전에는 가장 최근 기록을 항상 "지금 컨디션은 …"이라고 보여 줘서, 며칠 전 상태가 지금 상태처럼 보였습니다.

- **오늘 기록이 있으면**: "오늘 컨디션은 {기분}"
- **오늘 기록이 없으면**
  1. "오늘 상태를 아직 입력하지 않았어요"와 "오늘 상태 입력" 버튼
  2. 최근 14일 평균(평소 값이 있을 때). 오늘 상태를 추정한 값이 아니라고 적습니다.
  3. 오늘 날씨에 맞는 추천(아래 2번)
  4. "마지막 기록 · 3일 전(10월 2일)" 구역에 지난 Score, 기분, AI 코멘트, 지표, 추천
- 기존 통계로 오늘 상태를 **추정해 보여 주지 않습니다.** 측정하지 않은 값을 오늘 컨디션처럼 보여 주지 않기 위해서입니다.
- "오늘"은 한국 시간 기준 날짜입니다.
- 지난 기록에 대해서는 AI 코멘트를 자동으로 새로 만들지 않습니다(하루 생성 횟수를 아낍니다).

### 2. 오늘 날씨에 맞는 추천

- 오늘 기록이 없을 때 **"오늘 날씨로 추천 받기"** 버튼을 누르면, 현재 위치의 날씨로 음식 2개와 음악 2곡을 추천합니다.
- 버튼을 눌렀을 때만 위치와 날씨를 조회합니다. Dashboard를 열자마자 위치 권한을 묻지 않습니다.
- 서버로는 기온과 날씨 상태만 보냅니다. 좌표와 지역 이름은 보내지 않고, 조회한 날씨와 추천은 저장하지 않습니다.
- Check-in의 날씨 기준 추천과 같은 후보 목록, 같은 날짜별 순환, 같은 평가 반영을 씁니다. 다만 기분 정보 없이 고르기 때문에 같은 날 Check-in의 날씨 기준 추천과 항목이 다를 수 있습니다.

### 3. 체험 계정의 추천 평가

- "로그인 없이 둘러보기"에서도 좋아요 / 별로예요를 남길 수 있습니다.
- 체험 계정은 하나의 공유 계정이므로 평가도 모든 방문자가 함께 씁니다. 화면과 개인정보 처리 안내에 이 사실을 적었습니다.

### 4. AI 코멘트 Card 강조

- 한 단계 밝은 배경, 왼쪽 강조 선, "AI" 표시로 다른 Card와 살짝 구분됩니다. Dashboard, Check-in 결과, History의 주간 리포트에 같이 적용됩니다.

### 5. 다듬기

- **접근성**: 컨디션 Slider의 안내와 오류를 Screen Reader가 두 번 읽던 것을 없앴습니다. 값이 비어 있으면 "입력 안 함"으로 읽습니다.
- **로그인 화면**: 세 버튼의 높이를 52px로 맞췄습니다.
- **AWS Architecture 그림**: Service 아이콘을 넣고 Amazon Bedrock, Google / Kakao 호출 경로를 더했습니다.

### 6. 개발 과정

- CI가 바뀐 파일의 경로를 보고 필요한 Job만 돌립니다. 화면만 바꾸면 Backend Test를, 문서만 바꾸면 둘 다 건너뜁니다. 판단할 수 없으면 모두 실행합니다.
- `docs/07-TASKS.md`의 Task 절 형식을 하나로 통일하고 공통 규칙에 적었습니다.
