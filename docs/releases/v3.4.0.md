## 달라진 점

### 1. 홈 화면에 설치

- 화면 아래(Footer)와 아바타 메뉴에 **"앱 설치"** 버튼이 생겼습니다.
- Chrome / Edge / Android에서는 누르면 Browser의 설치 창이 뜹니다. 설치하면 주소창 없는 독립 창으로 열립니다.
- iPhone / iPad는 설치 창을 띄울 수 없어 "공유 → 홈 화면에 추가" 방법을 안내합니다.
- 이미 설치했거나 설치를 지원하지 않는 Browser에서는 버튼이 보이지 않습니다.
- 휴대폰에서는 "앱 설치"가 Footer 맨 위의 전체 너비 버튼으로 보입니다.
- Android 홈 화면에서 아이콘이 잘리지 않도록 전용 아이콘을 더했습니다.

### 2. History 그래프: 날짜별 평균과 확대

- 기록이 많아 점이 겹칠 때는 **날짜별 평균**(날짜마다 점 하나)으로 먼저 보여 줍니다.
- 두 손가락을 벌리거나 "+" 버튼을 누르면 **기록 전체**(기록마다 점 하나)가 나오고, 좌우로 밀어 지난 기록을 봅니다.
- 오므리거나 "날짜별 평균" 버튼을 누르면 평균으로 돌아갑니다.
- 화면이 넓거나 기록이 적으면 이전처럼 기록 전체를 그대로 보여 줍니다.
- 그래프 아래의 요약(기록 건수, 최저, 최고, 최근 점수)은 항상 실제 기록 전체 기준입니다.

## 넣지 않은 것

- 푸시 알림, Offline 동작, Service Worker. 설치만 지원합니다.
- 화면을 가리는 설치 유도 Banner. 사용자가 버튼을 누를 때만 동작합니다.
