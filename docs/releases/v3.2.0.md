## 달라진 점

### 1. 추천 5개 + 추천 음악 바로 듣기

- 추천 음식과 추천 음악이 각각 2개에서 **5개**로 늘었습니다(기분 기준 3개 + 날씨 / 상황 기준 2개).
- 추천 음악의 "바로 듣기"를 누르면 그 자리에서 YouTube 영상이 열립니다. 버튼을 누르기 전에는 영상을 불러오지 않습니다.
- Score와 기분을 정하는 규칙은 그대로입니다.

### 2. 날씨 자동 조회가 기본, 지역 이름 표시

- Check-in 화면에 들어오면 현재 위치의 날씨를 자동으로 조회해 "서울특별시 명동 · 맑음 · 23°C"처럼 보여 줍니다.
- "직접 입력"으로 바꿀 수 있고, 위치 권한이 없거나 조회에 실패하면 직접 입력 화면으로 바뀌어 제출이 막히지 않습니다.
- 좌표를 소수 2자리(약 1km)로 바꿔 기온 정확도를 높였습니다. 소수 1자리에서는 고도가 다른 지점으로 잡혀 기온이 약 1°C 어긋나는 경우가 있었습니다.
- 좌표는 저장하지 않습니다.

### 3. 로고와 파비콘

- 파란색에서 보라색으로 이어지는 사각형 안에 흰색 맥박선이 M 모양을 이루는 로고를 추가했습니다. 브라우저 탭, 홈 화면 아이콘, 상단 메뉴, README에 씁니다.
- 상단 메뉴의 로고를 누르면 첫 화면(Dashboard)으로 이동합니다.
