# 26. 개인별 평소 값과 신체 긴장도

TASK-056 / DEC-043, Human Approved 2026-10-05 (Gate B B안). 서비스용 Product Heuristic이며 의학적 기준이 아닙니다.

## 계산과 저장

주입된 Clock의 저장 시각에서 14일 전까지 같은 사용자 기록을 사용합니다. 시작 경계는 포함하고 저장 시각과 같은 기록 / 미래 기록은 제외합니다. 현재 기록은 계산 후 저장합니다. 5건 미만이면 평소 값이 없으며 기존 점수 / 기분 / 추천 / 요약과 같습니다.

심박수, 호흡수, 수면, 스트레스, 에너지 평균을 각각 소수 첫째 자리로 HALF_UP 반올림합니다. 심박수나 호흡수 평균이 0이면 비교하지 않습니다. 평균과 표본 수, 긴장도를 V7의 nullable Column으로 기록과 함께 저장하며 조회 시 다시 계산하지 않습니다. 차이는 저장된 입력에서 저장된 평균을 뺀 소수 첫째 자리 값입니다. 기존 행과 이전 버전 INSERT는 null을 유지합니다. 계정 삭제 때 Check-in 행과 함께 지워집니다.

## 긴장도와 조정

비율은 (오늘 값 − 평균) / 평균입니다. 반올림된 평균에 기준 비율을 곱해 차이와 비교하므로 부동소수점 경계 오차를 피합니다.

| 순서 | 표시 / Code | 기준 |
|---|---|---|
| 1 | 높음 / HIGH | 심박수 15% 이상 또는 호흡수 20% 이상 증가 |
| 2 | 안정 / STABLE | 두 값 모두 10% 이하 증가 (평균보다 낮아도 포함) |
| 3 | 보통 / NORMAL | 나머지 |

높음일 때만 ENERGETIC을 BALANCED로 조정합니다. 조정 뒤 BALANCED의 추천은 CALM Pool을 사용하며 TIRED / CALM은 자신의 Pool을 사용합니다. 상황 Pool, 날짜 순환, 개인 피드백과 음식 / 음악 각각 5개는 유지합니다. 기존 요약 뒤에 기준 이상으로 높은 지표를 지칭하는 휴식 제안 한 문장을 붙입니다. Wellness Score 공식은 바꾸지 않습니다.

예: 평균 심박수 100 / 호흡수 20일 때 오늘 115 / 20은 높음, 100 / 24도 높음, 110 / 22는 안정, 111 / 20은 보통입니다. 수면 86 / 스트레스 31 / 에너지 74의 Score는 긴장도와 관계없이 76입니다.

## 화면과 체험 계정

Dashboard와 결과 화면의 다섯 지표에 부호 있는 차이를 표시하고 0이면 “평소와 같음”을 표시합니다. 컨디션 / 결과 / 이력에 글자가 포함된 긴장도 Badge를 사용합니다. 5건 미만이면 기록을 쌓으라는 안내를 보여 줍니다.

체험 계정도 같은 계산을 사용하지만 공유 계정이므로 모든 방문자 기록의 평균입니다. 화면에서 이를 안내하고 개인 기록 비교를 위해 소셜 로그인을 제안합니다. AI에는 평소 값이 있을 때만 한국어 긴장도와 심박수 / 호흡수 차이를 추가하며 식별 정보는 보내지 않습니다.

## 한계와 검증

기록이 적거나 방문자 입력이 달라지면 평균이 흔들립니다. 입력 빈도에 따라 자주 입력한 시점의 영향이 커지며 일별 평균이나 휴식 상태 측정값을 보장하지 않습니다. 질병 / 진단을 뜻하지 않습니다. 저장된 평균은 이후 기록 변화로 갱신하지 않습니다.

Backend 경계 / 사용자 분리 / snapshot / API / AI 입력 / 삭제와 H2 및 MySQL Migration Test, Frontend 표시 Test를 둡니다. Smoke는 점수 / 지표 / 날씨 값을 비교하고 Baseline 영향을 받는 기분 / 요약 / 긴장도는 형식을 검사합니다. 최신 응답과 생성 응답의 동일성은 유지합니다. 검증 기준은 Orchestrator Verify입니다. 화면 캡처와 Merge 뒤 Staging 소셜 기록 5건 이상 확인은 Claude 세션 / Human 후속 작업입니다.
