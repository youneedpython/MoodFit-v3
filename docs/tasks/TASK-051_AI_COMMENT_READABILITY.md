## Human 지시와 확인된 사실 (2026-10-04)

1. Human: "AI 코멘트 아주 잘 실행되었어. 그런데 **줄바꿈이 되면 보기 더 좋을 듯** 해." — 지금은 코멘트 3문장, 주간 리포트 5 ~ 6문장이 한 덩어리로 이어져 나온다.
2. Human이 보낸 주간 리포트 화면에서 Claude 세션이 확인한 문제: 본문에 **내부 Code 이름이 그대로** 나온다("93점(ENERGETIC), 83점(BALANCED)"). 모델에 상태를 영문 Enum 이름으로 보내고 있기 때문으로 보인다. 화면의 다른 곳은 "활기 있음", "균형 있음" 같은 한국어 이름을 쓴다.
3. Human이 보낸 Check-in 결과 화면에서 Claude 세션이 확인한 문제: "AI 코멘트" Card **바로 아래에 날씨 / 지역 줄("흐림 · 17.9°C", "서울특별시 구로5동")이 간격 없이 붙어** 있고, 요약 문장과 AI 코멘트 Card 사이 간격도 좁다. AI 코멘트가 결과 요약과 날씨 정보 사이에 끼어 흐름이 어색하다.
4. Backend는 응답 Text에서 줄바꿈을 보존하고(TASK-045 Review 반영), Frontend는 줄바꿈을 CSS로 표시하게 되어 있다. 즉 모델이 줄을 나눠 주거나 Server가 나눠 넣으면 화면에 줄바꿈이 보인다.

## 설계 (실행 기준)

### 1. 줄바꿈

- **Prompt**: System Prompt의 형식 규칙을 고친다 — 코멘트는 "한 문장에 한 줄"(문장마다 줄을 바꾼다), 주간 리포트는 "2 ~ 3개 문단"(문단 사이에 빈 줄 하나, 문단마다 1 ~ 3문장). 목록 기호 / Markdown / 제목은 계속 금지한다.
- **Server 보정(결정적)**: 모델이 줄을 나누지 않았을 때를 대비해 응답 정리 단계에서 보정한다.
  - 코멘트: 응답에 줄바꿈이 하나도 없으면, 문장 끝 부호(`.`, `!`, `?`) 뒤에 **공백이 오는 위치**에서 줄을 바꾼다. 숫자 사이의 점("17.9도")처럼 뒤에 공백이 없는 점에서는 나누지 않는다.
  - 주간 리포트: 줄바꿈이 하나도 없으면 같은 규칙으로 문장을 나눈 뒤 **두 문장씩** 묶어 문단을 만든다(문단 사이 빈 줄).
  - 이미 줄바꿈이 있으면 그대로 둔다. 다만 연속된 빈 줄은 하나로 줄이고, 각 줄의 앞뒤 공백을 없앤다.
  - 길이 제한(코멘트 600자, 리포트 1200자)과 제어 문자 제거는 그대로 유지한다. 줄바꿈 문자는 제어 문자 제거에서 빼는 지금 동작을 유지한다.
- **Frontend**: 줄바꿈이 화면에 보이는지 확인하고(`white-space: pre-line` 등), 줄 / 문단 사이가 답답하지 않게 줄 간격을 기존 Token으로 맞춘다. HTML 삽입은 계속 금지한다.
- 이미 저장된 코멘트 / 리포트는 바뀌지 않는다(새로 생성하는 것부터 적용). 문서에 적는다.

### 2. 상태 이름

- 모델에 보내는 입력에서 상태(기분)를 **화면에 쓰는 한국어 이름**으로 보낸다(예: "활기 있음", "균형 있음"). 영문 Enum 이름을 보내지 않는다. 날씨 종류도 Enum 이름("CLEAR" 등)으로 보내고 있다면 한국어 이름("맑음" 등)으로 보낸다. 한국어 이름은 이미 Code에 있는 것을 쓴다(새로 짓지 않는다).
- System Prompt에 규칙을 더한다: 영문 Code나 내부 이름을 쓰지 않는다. 입력의 Key 이름을 그대로 옮기지 않는다.
- 보내는 Data의 범위는 그대로다(사용자 번호, 표시 이름, 지역 이름, 기록 id는 보내지 않는다). 이를 검사하는 기존 Test를 유지한다.

### 3. Check-in 결과 화면 배치

- "AI 코멘트" Card를 결과 요약의 **맨 아래**(날씨 / 지역 줄과 추천 목록 다음, "Dashboard로 이동" 같은 버튼 줄 위)로 옮기거나, 요약 문장 → 날씨 / 지역 → AI 코멘트 → 추천 순서로 자연스럽게 배치한다. 어느 쪽이든 **날씨 / 지역 줄이 AI 코멘트 Card 뒤에 붙어 나오지 않게** 한다.
- AI 코멘트 Card와 위아래 요소 사이 간격을 기존 Token으로 맞춘다(다른 구역 사이 간격과 같게).
- Dashboard의 AI 코멘트 위치(컨디션 Card 아래)는 그대로 둔다.
- 390 / 768 / 1280px에서 배치가 깨지지 않게 한다.

### Test

- Backend: 줄바꿈 없는 코멘트 → 문장마다 줄바꿈, 소수점에서 나누지 않음, 줄바꿈 없는 리포트 → 두 문장씩 문단, 이미 줄바꿈이 있으면 유지(빈 줄 정리만), 길이 제한과 함께 동작, 모델 입력에 영문 상태 / 날씨 Enum 이름이 없고 한국어 이름이 있음.
- Frontend: 결과 화면에서 AI 코멘트 영역이 날씨 / 지역 줄보다 뒤에 오고 그 뒤에 날씨 줄이 없음(DOM 순서), 줄바꿈이 있는 Text가 줄바꿈 표시용 Class / Style로 Render됨.
- 기존 Test는 그대로 통과해야 한다. Test의 타입 오류에 주의한다(`tsc --noEmit`). CSS 파일 내용을 `?raw` import로 읽어 검사하지 않는다(Test 환경에서 빈 문자열이다).
